# effect-of-fine-tuning-depth
A deep learning project that compares four fine-tuning strategies—Feature Extraction, Last Block Fine-Tuning, Partial Fine-Tuning, and Full Fine-Tuning—using EfficientNet-B0 and the Oxford-IIIT Pet dataset. Model performance is evaluated using accuracy, precision, recall, and F1-score to identify the most effective fine-tuning strategy.
